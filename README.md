# Web_FindMyStuff
Lost &amp; Found Portal
procedure:-
⭐ Step 1: Create Your Project Folder

Right-click on your desktop

Click New Folder

Name it: lost-found-portal

This is like your school bag.

⭐ Step 2: Open Folder in VS Code

Open VS Code

Click File → Open Folder

Select: lost-found-portal

Now VS Code is ready.

⭐ Step 3: Create All Files

In VS Code:

Right-click inside folder

Click New File

Create these:

index.html
report.html
search.html
admin.html
success.html
style.css
app.js


Each file is like a notebook for different subjects.

⭐ Step 4: Paste the Code

I will give you all the code once you say "give code".

Paste each code into the correct file.

⭐ Step 5: Install Live Server

In VS Code → Left side click Extensions

Search: Live Server

Install it

Live Server helps you run your website like a real website.

⭐ Step 6: Run the Website

Right-click index.html

Click Open with Live Server

Your website opens in your browser 🎉

🧠 6. How the Website Works (Explained in Kid Language)

✔ When someone reports a lost item →
It gets saved in the browser’s small memory called localStorage.

✔ When someone searches →
The website looks inside that memory to find matching items.

✔ Admin sees all lost/found items
Because admin page reads from the same memory.

No need for database.
No need for server.
Everything works locally.

Very easy + beginner-friendly.
